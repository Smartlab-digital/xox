# XOX

Responsive homepage prototype for a social marketplace of things and services.

Open `index.html` directly for the interactive front end. The PHP starter has a SQLite database and endpoints:

- `GET /api/listings`
- `POST /api/listings`

To start a local PHP server: `php -S localhost:8000`.
